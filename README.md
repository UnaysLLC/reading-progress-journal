# Reading Progress Journal

A local reading tracker for books, page progress, and short reflections. Designed for learners who want a simple journal without creating an account.

## Features

- Add books with current and total page counts
- Visual progress and reading statistics
- Update or remove entries
- Optional short reflection for each book
- Local-only storage and responsive design
- Export the journal as JSON

## Run locally

Open `index.html` in a modern browser.

## Privacy

The journal uses browser `localStorage`; no reading information is sent to a server.
